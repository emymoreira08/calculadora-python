# Calculadora em Python

Projeto desenvolvido em Python com o objetivo de praticar conceitos fundamentais de programação e construção de aplicações interativas no terminal.

## Funcionalidades

- Adição
- Subtração
- Multiplicação
- Divisão
- Validação de entradas numéricas
- Tratamento de erros com `try/except`
- Prevenção de divisão por zero
- Menu interativo para seleção de operações
- Opção para realizar novos cálculos sem reiniciar o programa

## Conceitos utilizados

- Funções (`def`)
- Parâmetros e retorno (`return`)
- Estruturas condicionais (`if`, `elif`, `else`)
- Estruturas de repetição (`while`)
- Tratamento de exceções (`try/except`)
- Manipulação de strings
- Tuplas e múltiplos retornos
- Organização e modularização do código

## Tecnologias

- Python 3

## Como executar

1. Clone este repositório:

   ```bash
   git clone  https://github.com/emymoreira08/calculadora-python.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd calculadora_simples
   ```

3. Execute o programa:

   ```bash
   calculadora_simples.py
   ```

## Objetivo

Este projeto faz parte da minha jornada de aprendizado em Python, com foco no desenvolvimento de lógica de programação, resolução de problemas e construção de aplicações práticas.
